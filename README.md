# Brasa & Sabor - Hamburgueria em Osasco

Site funcional de hamburgueria artesanal em Osasco.

**Objetivo:** Amostra de portfólio para mostrar para donos de comércios locais como um site pode vender sozinho.

## Funcionalidades

- Cardápio interativo com filtros
- Carrinho de compras funcional
- Checkout direto no WhatsApp
- Design responsivo (mobile-first)
- Animações suaves
- Visual premium (tema escuro + laranja)

## Como rodar localmente

Basta abrir o `index.html` no navegador.

## Publicação

Site publicado via GitHub Pages.
